Augur uses two contemporary sans-serif families with distinct roles.
**Sora** is the primary voice: display, headings, controls, key actions,
and primary navigation. **Schibsted Grotesk** is the supporting voice:
paragraphs, helper text, metadata, tables, and dense UI text. Families
are never alternated for decoration; each text element has one clear
role. Both are delivered self-hosted through the package stylesheet
entry — no font CDN, no third-party request.

## Loading behavior

`import "@augur/design-system/styles.css"` pulls the pinned
`@fontsource` packages (Sora 400/600, Schibsted Grotesk 400) into the
consumer's bundle, so font files are served from the same origin as the
site. The `--augur-font-primary` / `--augur-font-secondary` custom
properties carry fallback stacks, so text remains readable while faces
load. The executable evidence for delivery — `document.fonts.check()`,
computed role values, and the absence of console or network failures —
lives in the package font fixture.
