## The approved text identity

The identity is live text in the system's own typography. It has no
drawn mark, no container, and no image file. It is two elements set as
one quiet lockup:

| Element | Voice and role | Treatment |
| --- | --- | --- |
| Wordmark “Augur” | Sora 400 — the editorial-title role at opening scale (40/48, −0.01em; 32/40 below 600px) | Sentence case. Never uppercase, never semibold, never Sora Light. The regular weight is the identity's voice. |
| Descriptor “Design system” | Schibsted Grotesk 400 — the editorial-label role (12/16, 0.12em tracking), uppercase | The quieter element: smaller scale, secondary color, tracked short label. One or two words; it never wraps mid-phrase. |

The editorial roles are the recorded contract direction; issue 45
performs their canonical migration into `DESIGN.md` and the generated
typography layer. Until then the role metrics above are the
specification, exactly as recorded in the
[visual direction](/foundations/visual-direction) contract.

Color is semantic and theme-adaptive: the wordmark uses the foreground
text color and the descriptor the secondary text color of the active
theme, through the existing token relationships. There are no
fixed-color variants, no reversed special edition, and **no accent color
in the lockup** — accent is the one-signal/action voice, and the
identity never spends it.

### Prohibitions

- No reconstructed, recolored, stretched, cropped, traced, or redrawn
  mark — nothing may be extracted from the PDF (see the provenance
  record's usage constraints).
- No logo component, logo image, SVG mark, or font-based glyph
  pretending to be one may exist while masters are unresolved.
- No container, box, pill, or panel around the lockup; the identity is
  bare text on the surface it sits on.
- No letterspacing, casing, or weight inversion of the wordmark; no
  extra weights (only Sora 400/600 and Schibsted Grotesk 400 are
  delivered).
- The neutral favicon anchor (issue #7) stays as documented shell
  chrome; it is deliberately not a mark and must not drift toward one.

## Delivery instructions

| Concern | Rule |
| --- | --- |
| Exact files | Specification: this page and its clean Markdown endpoint. Asset record: `resources/brand/PROVENANCE.md`. Runtime type roles: `packages/design-system/src/styles/typography.css` (canonical migration in issue 45). Adoption surfaces: the docs shell brand region (`apps/docs/src/layouts/BaseLayout.astro`, issue 46) and the home route (issue 47). Rendered reference: the visual contract fixture's opening frame and its retained captures. |
| Theme variants | Light and dark only, through the semantic text-color relationships above. Both themes render the same text, sizes, and geometry. |
| Aspect ratio | None. The text identity is live text and has no canvas or fixed proportions. The PDF's lockup ratios and minimum sizes (recorded in the foundation decision audit) bind only the official masters when they arrive. |
| Clearspace | Interim text rule: at least one descriptor line-height (16px) of clear space on all sides inside UI chrome. In composed openings, the frame gutters and section spacing govern instead of extra padding. The PDF's clearspace rules for drawn marks do not apply to text. |
| Minimum size | The descriptor never renders below 12/16 with its full 0.12em tracking; if the space cannot fit that, the descriptor is omitted — never shrunk, condensed, or de-tracked. The wordmark's floor in shell chrome is the ui role (14/20) pending issue 46's adoption. |
| Fallback behavior | When verified masters arrive, a maintainer decision updates the provenance record (its §3 and rule 4), and the official artwork replaces the text lockup per PDF §01.1: always start from a supplied file. Until then, no intermediate logo approximation is permitted. |

## Adoption and scope

The docs shell currently renders the text string “Augur Design System”
as shell chrome plus a neutral anchor square. That predates this
specification; aligning the shell with the lockup above is issue 46's
scope, and composing the home opening with it is issue 47's. The first
sanctioned render of the lockup therefore happens in those issues, from
this page as the linked reference.
