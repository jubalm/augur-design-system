Augur's visual direction is a maintained system of decisions, not a collection of isolated page treatments. It translates recurring structures in the brand foundation into reusable interface behavior: clear priority, restrained signals, square geometry, tonal depth, and equal light/dark treatment.

## What the system should communicate

Augur should make the important question, state, or next action easy to find without making every region compete for attention.

The recurring principles are:

- one clear focal point per task area;
- open composition before unnecessary containers;
- quiet supporting information around explicit primary content;
- square, precise geometry;
- tonal separation instead of decorative depth;
- green used as an intent or orientation signal, not as decoration;
- equal structure and behavior in light and dark themes;
- concise copy that names state and consequence directly.

These principles guide new work even when a page does not resemble one of the original reference compositions.

## Composition

Lead with the page purpose, primary message, or decision. Secondary context should remain available without competing at the same visual level.

Use alignment, spacing, and reading measure to create grouping before adding another panel. Long-form prose stays near 65ch. Dense records, specimens, and tables may use a wider content region when the information would otherwise become difficult to scan.

The documentation shell has its own 1400px maximum frame for dense reference content; that is a scoped reading-shell decision, not a universal application width. See [Layout and geometry](/foundations/layout-geometry).

## Typography

Sora carries identity, editorial titles, interface headings, controls, and primary navigation. Schibsted Grotesk carries paragraphs, helper text, metadata, tables, and dense records.

Editorial titles and sections use regular-weight Sora where size is sufficient to establish hierarchy. Interface headings and controls retain their stronger roles. Do not stack large size, heavy weight, uppercase, and green on the same message to manufacture importance.

See [Fonts and typography](/foundations/fonts) for the maintained role definitions.

## Color and signal

Navy and Paper establish the primary canvases. Green is reserved for intent and orientation: the primary action, focus, active state where appropriate, or a short signal rule.

A coherent task area should usually have one dominant green carrier. Do not add a green stripe, success dot, or accent treatment to every card or section.

On light surfaces, Deep carries readable green intent. On dark surfaces, Augur Green carries the brighter signal. See [Color system](/foundations/color) for semantic roles and contrast constraints.

## Surfaces and borders

Depth is tonal rather than ornamental. Light UI steps from Paper to White and Muted; dark UI steps from Navy through Surface 1, Surface 2, and Surface 3.

Use quiet separators for editorial grouping and more perceivable edges for interactive controls. Meaningful boundaries must remain visually distinguishable; quiet rules must not be asked to carry state or interaction meaning by themselves.

No decorative shadows, glows, gradients, bevels, or textures are part of the default system.

## Shape

Panels, controls, Dialog surfaces, specimen fields, and standard triggers use 0px radius. Circular geometry is reserved for controls whose interaction model requires it and for verified supplied artwork.

Square geometry is a system rule, not a page-specific styling choice.

## Interaction

State feedback is immediate. New components do not add decorative transitions simply to make an interface feel polished.

Keyboard focus uses the shared 2px `:focus-visible` ring with a 2px offset. Disabled, loading, invalid, selected, and record states must be explicit in semantics or copy rather than communicated by color alone.

See [Interaction](/foundations/interaction) for the complete shared contract.

## Theme and adaptive behavior

Light and dark are two expressions of one system. Theme changes color roles only; content order, spacing, dimensions, hierarchy, and interaction behavior stay equivalent.

Responsive layouts preserve the same priority order. Columns may stack and supporting information may move below the primary content, but the page should not acquire a different meaning or action hierarchy at another viewport.

## Reference compositions

Three source-grounded compositions remain useful as review evidence:

- **Brand opening:** an unboxed message, orientation rail, one short signal, and supporting metadata.
- **Editorial specimen:** open columns and tonal specimen fields with supporting explanation outside unnecessary cards.
- **Compact record:** explicit state, question, equal choices, response, and quiet metadata in a dense record composition.

They demonstrate the principles above. They are references, not templates that every page must reproduce.

## Provenance and acceptance

The visual direction was derived from the pinned Augur brand foundation PDF and the recorded foundation review. Adopted values that fit the pinned `DESIGN.md` schema are canonical there; maintained guidance on this site owns the decisions that do not fit the schema cleanly.

The detailed source-page comparisons, review captures, and historical selection record remain available in the repository and linked issues.

Passing deterministic tests establishes implementation consistency, not aesthetic acceptance.
