## From proposals to decisions

The original issue 2 proposals are preserved in the
[foundation decision history](/foundations/decisions). Their unresolved status was
not settled by issue closure. On 2026-09-06, the maintainer delegated the exact
visual choices to the Astra visual director through the
[issue 42 authority record](https://github.com/jubalm/augur-design-system/issues/42#issuecomment-5556190059).
The [visual direction contract](/foundations/visual-direction) is the selected
implementation direction; final human visual acceptance remains pending in issue 53.

## Selected foundation direction

| Concept | Selected direction |
| --- | --- |
| Spacing | Local 4/8/12/16/24/32px steps; explicit 48/64/80px composition roles; 1200px frame, 64/24px minimum gutters and 80/48px section gaps |
| Sizing | Desktop 32/36/40px controls, 16/20px icons; at least 44×44px actionable targets on coarse pointers |
| Radius | Square 0px panels, controls, and Dialog; reject old 8/6px proposal |
| Focus | 2px ring with 2px offset, Deep on light and Green on dark, honoring focus-visible heuristics |
| Motion | Immediate 0ms feedback; no decorative motion; retain reduced-motion protection during migration |
| States | Explicit inherited state names; neutral hover/selection and labeled disabled/loading treatment |

## Migration and acceptance

Issue 42 confines its new geometry and border relationships to a non-shipping
reference fixture. Issue 45 encodes representable adopted values in `DESIGN.md`,
regenerates the package outputs, and documents schema-external relationships.
Assigned component and docs work then consumes those maintained foundations.
Do not hand-edit generated files or treat a product's local tokens as authority.

Use the complete [type, layout, interaction, signal, and border contract](/foundations/visual-direction)
for exact values and breakpoint behavior. The prior blanket statement that every
proposal is unadopted is historical. Final human acceptance and release approval
remain distinct from the adopted implementation direction.
