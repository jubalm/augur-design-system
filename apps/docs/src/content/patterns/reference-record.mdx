The reference record realizes the approved frame C with package
components and static fixture content: a lifted square panel inside a
quiet outer field, a 32×2 state signal, the question as the first
substantive focal point, two choices with equal structure and
emphasis, and an explicit, quiet response. The rendered pair pins one
light and one dark panel — identical content, order, and geometry
under either host theme. All content is illustrative static data; this
pattern owns no product submission workflow, and neither does the
package.

## When to use

- For read-only records that lead with a question or decision and its
  current state — anywhere the reader inspects rather than submits.
- When the state must be explicit and quiet: a short signal, a named
  state, and a labeled response, never color alone.

## When not to use

- For live voting or submission flows; this pattern records, it does
  not collect.
- When a question is not the first substantive element — use
  [PageHeader](/patterns/page-header) for page wayfinding instead.

## Anatomy and rules

- **State rail first**: the 32×2 signal plus the explicit state label
  ("Open query") and identifier ("LQ-042") open the panel — the record's orientation, quiet by design.
- **Question leads**: the first substantive element is the question
  (heading-2 role, 20/26 as in the approved frame), larger than every label around it.
- **Equal choices**: both choices share geometry, variant, and
  emphasis; neither is selected. The explicit response is "Not submitted".
- **Quiet metadata**: response and query identity sit in the body and
  metadata roles; separators and insets follow the encoded spacing
  tokens (24px panel insets and choice gap; 16px below 600px).
  Status, response, and closing time ("14:32 UTC") pair left labels with
  right-aligned values. The question is "Did the proposal pass before 30 June?".
- **True theme pair**: the light and dark panels pin their themes, so
  the pair stays honest under either host theme.

## Accessibility

The state label and response are real text; the signal is
`aria-hidden`. Choices remain real package buttons, explicitly `aria-disabled` and
without handlers. They do not suggest a recorded selection or working voting. Contrast follows the recorded
pairings — labels clear 4.5:1 against their fills in both themes.

## Design rationale

Frame C preserves the source records (PDF pages 20, 23, and 25): the
question, equal choices, state, and response stay readable in both
themes; the signal is short and separate from choice emphasis. The
