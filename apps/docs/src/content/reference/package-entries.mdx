`@augur/design-system` is source-based. Workspace applications can import it directly; external consumers can install generated source through the shadcn-compatible registry.

The package exposes three public package entry points:

| Entry | What it delivers |
| --- | --- |
| `@augur/design-system` | Public React components/patterns, component types/helpers, and font provenance constants/types |
| `@augur/design-system/styles.css` | Aggregated font faces, generated tokens, semantic themes, typography roles, shared focus behavior, and component/pattern styles |
| `@augur/design-system/fonts.css` | Voice-family custom properties and fallback stacks only; it does not load font files |

Internal source paths are not public API.

## Root module

The root module exports the maintained starter components and patterns, including Button, Card, Input, Dialog, PageHeader, EmptyState, and FormField, together with their public types/helpers where applicable.

## Aggregated stylesheet

Most consumers should load the full stylesheet once:

```ts
import "@augur/design-system/styles.css";
```

This is the shared visual contract for package consumers: self-hosted font faces, generated design values, semantic role mapping, typography, focus behavior, and component/pattern styling.

## Fonts-only stylesheet

Consumers that deliver font files by another route but still want Augur's family stacks can import:

```ts
import "@augur/design-system/fonts.css";
```

This defines `--augur-font-primary` and `--augur-font-secondary` with their maintained fallback stacks. It intentionally contains no `@fontsource` imports; self-hosted font-face delivery comes from the aggregated stylesheet.

## Source registry

The registry is a distribution channel, not a second implementation. Generated items are derived from canonical package sources and published under `/r/`.

Start external consumption with `augur-theme`, then install the required component/pattern items. Pin a verified repository ref for reproducibility.

See [Getting started](/getting-started) for the source-install flow. Registry generation and validation are checked in the repository so committed output cannot drift silently from package sources.

## Provenance

Font licenses and source details are recorded in [resources/brand/PROVENANCE.md](https://github.com/jubalm/augur-design-system/blob/main/resources/brand/PROVENANCE.md). Design-value authority remains in `DESIGN.md`; generated entries are derived outputs.
